Cómo mejorar la evaluación

La aplicación debe probarse con sorteos pasados sin usar información futura (backtesting). Se comparará la tasa de aciertos del método con una selección aleatoria antes de afirmar que mejora los resultados.

En un sorteo justo, cada combinación exacta de 000 a 999 tiene una probabilidad teórica de 1 entre 1.000. Los resultados anteriores no garantizan resultados futuros.

Importar datos de sorteos

Importa un CSV con columnas date,result, por ejemplo 2026-10-20,407. Mantén los ceros iniciales en los resultados.

Los registros se guardan en este navegador. Cambiar de navegador o borrar sus datos puede eliminarlos.

Fuente de datos

Para un análisis fiable, importa resultados oficiales separados por estado y modalidad de sorteo. Esta versión permite elegir Florida o Georgia, pero el archivo CSV debe corresponder al estado seleccionado.

🔄 Actualización de sorteos

Configura una fuente de datos compatible. Para sincronizar automáticamente se necesita una API o servicio intermediario que entregue JSON; las páginas oficiales pueden bloquear consultas directas desde el navegador.

Formato esperado: JSON con una lista de objetos: [{"date":"2026-10-22","draw":"Midday","result":"407"}]. El servidor debe consultar una fuente fiable y normalizar los datos.

Estado: sin sincronizar. La actualización automática funciona mientras esta aplicación esté abierta y la pestaña activa; no es un servicio Android en segundo plano.
